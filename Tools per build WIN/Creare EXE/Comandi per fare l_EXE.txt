# BUILD EXE + MSIX DATAFLOW (Windows pulito)  

## 1. Installazione base  
Scaricare e installare Python (consigliato 3.11 o 3.12)  
Durante installazione: spuntare "Add Python to PATH"  

Verificare installazione:  
python --version  

---  

## 2. Preparazione progetto  
Copiare la cartella del progetto DataFlow su Windows  
Entrare nella cartella:  
cd "C:\percorso\del\progetto"  

Verificare presenza file:  
- DataFlow.spec  
- app.manifest  

---  

## 3. Creazione ambiente virtuale  
python -m venv venv  

---  

## 4. Installazione dipendenze  
venv\Scripts\python -m pip install --upgrade pip  
venv\Scripts\python -m pip install -r requirements.txt  

Installare PyInstaller:  
venv\Scripts\python -m pip install pyinstaller  

---  

## 5. Build EXE  
venv\Scripts\python -m PyInstaller DataFlow.spec  

---  

## 6. Output EXE  
dist\DataFlow\  

---  

## 7. Verifiche post-build  
Avvio EXE  
Verifica GUI (Tkinter)  
Verifica icona  
Verifica traduzioni (locale)  
Verifica accesso database SQLite  
Test funzionalità principali  

---  

## 8. Creazione pacchetto MSIX  
Aprire MSIX Hero  
Creare nuovo pacchetto da cartella  
Selezionare contenuto di: dist\DataFlow\  

Configurare:  
- Nome app  
- Publisher  
- Versione  
- Logo  

Generare file .msix  

---  

## 9. Firma pacchetto  
Usare MSIX Hero oppure signtool  

Esempio:  
signtool sign /fd SHA256 /a /f certificato.pfx DataFlow.msix  

---  

## 10. Test installazione  
Aprire file .msix  
Verificare installazione corretta  
Avviare app  

---  

## 11. Windows App Certification Kit (WACK)  
Aprire WACK  
Selezionare app installata  
Eseguire test  

Se errori → correggere e rifare build  

---  

## 12. Pubblicazione  
Caricare .msix su Microsoft Partner Center  

---  

## 13. Note importanti  
Non serve activate.ps1  
Usare sempre python del venv  
Ogni progetto deve avere il proprio venv  
PyInstaller compila solo per il sistema corrente  

---  

## 14. Workflow completo  
Linux → sviluppo  
Windows VM → build EXE  
Windows VM → MSIX + WACK  
Microsoft Store → pubblicazione

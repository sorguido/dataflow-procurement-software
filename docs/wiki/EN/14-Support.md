
---

## Bug Reports and Feature Requests

DataFlow is an open-source project. Bug reports and feature requests should be submitted on GitHub in the **Issues** section:

**GitHub Repository:** [github.com/guidosoraru/dataflow](https://github.com/guidosoraru/dataflow) *(verify the current link in the application footer)*

### How to write a useful bug report

Always include:

1. **DataFlow version** (e.g. v2.1.0)
2. **Operating system** (e.g. Windows 11 64-bit, Ubuntu 22.04)
3. **Problem description**: what you were doing, what happened, and what you expected instead.
4. **Steps to reproduce** (if known).
5. **Log file**: attach the `dataflow.log` file (see [Logs and Diagnostics](13-Logs-and-Diagnostics.md) for its location).

## Updates

DataFlow does not update automatically. To check whether a newer version is available, visit the GitHub repository listed above.

Before installing an update:

1. Run a **manual database backup** (⚙️ Settings → 💾 Manual Backup).
2. Install the new version.
3. Launch DataFlow and verify that all data is accessible correctly.

# 14 – Supporto

## Informazioni sulla versione

Prima di contattare il supporto, annotare la versione di DataFlow in uso. La versione è visibile nel piè di pagina della schermata principale:

```
v2.2.0 - Sviluppato da Guido Sorarù © 2025–2026
```

---

## Segnalazione bug e richieste

DataFlow è un progetto open source. Le segnalazioni di bug e le richieste di nuove funzionalità vanno inserite su GitHub nella sezione **Issues**:

**Repository GitHub:** [github.com/guidosoraru/dataflow](https://github.com/guidosoraru/dataflow) *(verificare il link aggiornato nel footer dell'applicazione)*

### Come scrivere una buona segnalazione bug

Includere sempre:

1. **Versione di DataFlow** (es. v2.2.0)
2. **Sistema operativo** (es. Windows 11 64-bit, Ubuntu 22.04)
3. **Descrizione del problema**: cosa si stava facendo, cosa è successo, cosa ci si aspettava invece.
4. **Passaggi per riprodurre il problema** (se noti).
5. **File di log**: allegare il file `dataflow.log` (vedere [Log e diagnostica](IT-13-Log-e-diagnostica) per la posizione).

---

## Contatto diretto

Per richieste specifiche non adatte a un issue pubblico (es. uso aziendale, personalizzazioni), è possibile contattare lo sviluppatore tramite:

- **LinkedIn**: il link è cliccabile nel piè di pagina dell'applicazione.

## Licenza

DataFlow è rilasciato sotto licenza **GNU General Public License v3 (GPLv3)**. I dettagli completi sono visibili facendo clic su **≡ License** nella barra degli strumenti dell'applicazione.

La licenza GPLv3 garantisce la libertà di utilizzare, studiare, modificare e distribuire il software, a condizione che le versioni derivate siano distribuite con la stessa licenza.

---

## Aggiornamenti

DataFlow non si aggiorna automaticamente. Per verificare se è disponibile una versione più recente, controllare il repository GitHub indicato sopra.

Prima di installare un aggiornamento:

1. Eseguire un **backup manuale del database** (⚙️ Impostazioni → 💾 Backup Manuale).
2. Installare la nuova versione.
3. Avviare DataFlow e verificare che i dati siano accessibili correttamente.
